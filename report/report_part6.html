6. Inference functions

Each model has its own function: predict_podium_lr, predict_podium_rf, predict_podium_gb_default, predict_podium_gb_tuned and predict_podium_nn (D27). Each takes one driver's pre-race information as a dictionary and returns the podium probability, a yes/no decision at that model's validation-tuned threshold, and the list of missing features. predict_podium_lr is the recommended one (Section 4.5). All five share one input check and use their model's own fitted preprocessing, so missing values are treated exactly as in training (training median plus the "was missing" indicator).

  • Required: grid_pos and field_size. A raw grid of 0 is read as a pit-lane start and moved to the last slot (D7).
  • Derived when absent: grid_pct from slot and field size, and grid_penalty from slot and qualifying position.
  • Rejected with an error: unknown feature names (a typo would otherwise silently count as "missing"), a grid slot outside the field or not a whole number, shares and rates outside 0–1, and a grid_pct that contradicts the slot.

  • For the recommended logistic regression, removing information lowers the probability step by step (0.735 → 0.603 → 0.539 → 0.391): without qualifying it no longer knows he was fastest, and without form it no longer sees his podium run. That is the behaviour a user would expect.
  • The network moves the other way (0.513 → 0.833). In training, a row without qualifying is almost always a pre-1994 row, and a row without form is a debutant; a veteran with both missing is a pattern the network never saw, so its output is not reliable there.
  • The lesson: an imputed prediction is only as good as the training data's examples of that missing pattern. That is why every function returns the list of missing features, and why the realistic partial demo (a debutant) is the one a user will actually meet.

7. Known limitations

  • Historical qualifying-coverage drift. Qualifying data starts in 1994 and is patchy until 2002 (100% of 1950–1993 rows and 53.6% of 1994–2002 rows have no qualifying position). The models learn qualifying mostly from 2003 on, and the missing indicators double as an "old era" marker, which makes records with qualifying missing less reliable (Section 6). Keeping these seasons was tested, not assumed: no later start year predicts better, and starting in 1994 is significantly worse (Section 3.4); filling qualifying with the grid slot instead of the median was also worse (notebook §8.5).
  • Era sensitivity. Rules, reliability and field sizes changed a lot. A pole start converts 51%, 65% or 81% depending on the era (Figure 1.6), and the old seasons are much harder to rank. The test seasons start a new set of technical rules and the models still transfer, but a future rule change may not behave the same way.
  • Small evaluation sets. Validation has 39 races and test 68, so PR-AUC intervals are about ±0.06–0.11 wide. Differences between our learned models are inside them. Validation scores are slightly optimistic, because validation was used for several choices.
  • Independent predictions. Each driver is scored alone. Nothing forces exactly three podiums per race, so the yes/no output of the logistic regression predicts about 4–5 per race. A race-level model (Plackett–Luce or a conditional logit) would fix this; it is out of scope for this milestone.
  • No race-day information. Weather, tyre strategy, safety cars, crashes and breakdowns are not in the data and cause many upsets. The most confident miss is a pole-sitter's brake failure (Section 5.4).
  • Team identity in the features. A renamed team gets a new constructorId, so its constructor form history restarts at the rename. Q3 groups teams by lineage; the features do not.
  • Data quirks documented but not fully fixable: shared drives in the 1950s (the starting car cannot always be identified, D4, and one race still has four podium rows); a few vacant positions after disqualifications (D8); the broken race times of the 2024 Belgian GP (Section 1.3); some cars that failed before the start are coded as 0-lap retirements and count as starts in Q3; and for raw grid 0, telling a pit-lane starter from a car that never started uses the post-race laps column (D6, D7), which affects a handful of rows.

How to reproduce

On Kaggle: attach the dataset, turn Internet on (the first cell installs shap, lime or statsmodels if missing), and press Run All. Locally: put the 14 CSVs in data/, install requirements.txt, run all cells. The notebook writes the tables and every figure of this report to outputs/; this report is rebuilt from report/ with python report/build.py. The cleaning, the DE answers, the logistic regression and gradient boosting are deterministic; the random forest and the network are seeded and report their spread over three seeds.
