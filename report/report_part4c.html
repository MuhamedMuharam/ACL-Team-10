Limitations shared by all models.

  • Each driver is scored independently. Nothing forces exactly three podiums per race, so the yes/no output predicts 3–5 per race. A race-level model such as Plackett–Luce or a conditional logit (Henderson & Kirrane, 2018) would solve this; it is out of scope here.
  • No race-day information. There is no weather, tyre strategy, safety car, crash or breakdown data, so upsets cannot be foreseen (Section 5.4).
  • Small evaluation sets. Validation has 39 races, so model and threshold choices carry noise, and validation scores are slightly optimistic because validation was used for several choices. Test has 68 races, and its intervals are about ±0.06 wide.
  • Era shift. The test seasons started a new set of technical rules, and the models still transfer to them. A future rule change may not behave the same way.
