4. Predictive modeling

Every model predicts, for one driver on the grid of one race, the probability of finishing in the top three (positionOrder ≤ 3). It uses only information known after qualifying and before the start.

4.1 Set-up: same rows, same features, choices on validation only

All models are trained and evaluated on the same modeling table: one row per driver per race, and the same 18 pre-race features in five groups (Section 3). Rows are split by season:

Preprocessing (Section 3.5) is fitted on the training rows only: median imputation with 14 "was missing" indicators (32 inputs), plus StandardScaler for the logistic regression and the network.

4.2 Metrics, threshold and uncertainty

  • Primary metric: PR-AUC (average precision). Podiums are rare (≈ 15%), and PR-AUC scores how clean the top of the ranking is. A random model's PR-AUC is the base rate (0.15), while its ROC-AUC is 0.5.
  • Secondary metric: ROC-AUC, for the overall separation of podium from non-podium.
  • F1, precision and recall at one decision threshold per model: the threshold that maximises F1 on validation, then used unchanged on train and test (D22).
  • Accuracy is not used: a model that always says "no podium" has accuracy 0.850 on validation and test and recall 0.
  • Brier score checks calibration: whether a predicted 0.3 really means about 30%. This matters because the inference functions return a probability.
  • Uncertainty. Validation has only 39 races, so each important number gets a 95% interval from 1,000 bootstrap resamples of races (drivers in one race are not independent). A difference between two models is resampled paired, with both scored on the same redrawn races (D23).

Early stopping is off for gradient boosting (D28). scikit-learn's default switches it on above 10,000 rows and holds out a random 10% of rows, which would mix drivers of the same race and make results depend on the seed. The number of trees is tuned on validation instead.

Class imbalance (D20). No model uses class weights. Weights make the rare class count more, but they push every predicted probability up, and the inference functions return a probability (van den Goorbergh et al., 2022). What training and validation show

  • Overfitting is visible, then removed. Default gradient boosting fits the training seasons far better than anything else (train PR-AUC 0.765) but reaches 0.724 on validation. The tuned settings learn slowly with very simple trees (0.574 train, 0.736 validation). The best point is the corner of the grid (slowest learning, fewest trees, smallest trees), which suggests an even simpler model would do about as well.
  • Validation is above training for every model, even for the grid rule (0.496 train vs 0.639 validation), which learns nothing, so this is not leakage. The old seasons are much harder to rank: grid-rule PR-AUC 0.39–0.46 per decade before 1994, against 0.68–0.70 in 2014–2019 (bigger fields, frequent breakdowns). The baseline beats the grid rule in every period.
  • Seed spread. Over 3 seeds, the forest's validation PR-AUC ranges 0.723–0.733 (mean 0.728; test mean 0.723), the network's 0.716–0.721 (mean 0.719; test mean 0.697). Differences between models smaller than this mean little.

  • No model earns its extra complexity. Every interval includes 0. This test even favours tuned gradient boosting, the best of 54 tries on the same 39 races, and it still does not clear the bar.
  • The baseline clearly beats the grid rule (0.031 to 0.144): standings, form and qualifying pace add real information on top of starting position.
  • The test seasons confirm the recommendation was not costly. Logistic regression 0.722, random forest 0.722, network 0.711, tuned and default gradient boosting 0.696 and 0.693, all well inside each other's intervals (about ±0.06).
  • Why the logistic regression is the recommended model (used first in Sections 5 and 6): it is as good as any other model, the simplest, deterministic, and among the best calibrated (validation Brier 0.067, with the random forest 0.067 and the network 0.068; tuned gradient boosting 0.094 keeps its predictions near the average).

What the comparison shows

  • The learned models clearly beat the grid rule, but not each other.
  • Calibration. Without class weights, the logistic regression, the random forest, the network and default gradient boosting all lie close to the diagonal. Tuned gradient boosting is under-confident at the top: its slow learning keeps predictions near the base rate.
  • Race top-3 hit rate. Taking the three highest scores in each race, the learned models catch about as many podium finishers as the first three on the grid (validation 0.675 vs 0.692; test 0.637–0.662 vs 0.647). Their advantage is not in reordering the front of one grid, but in knowing how likely each front-runner is to podium (a front-row start in the dominant car vs a midfield car), which PR-AUC and the Brier score reward.
  • Decisions at the threshold. The logistic regression's F1-optimal threshold is low (0.241), so it predicts about 4.0 podiums per race on validation and 4.8 on test, more than the 3 possible. This follows from scoring each driver on their own (Section 4.7).
