4.6 Feature-group ablation

Section 3 justified each feature before training. The ablation measures each group's contribution after training: we remove one group at a time and retrain with rows, hyperparameters and preprocessing unchanged, for all five models (the forest and the network averaged over 3 seeds), each change with a paired race-bootstrap interval. Rule (D30): a group or feature is removed from a model only if removing it improves that model's validation PR-AUC with an interval entirely above 0.

Table 4.7 Change in validation PR-AUC against all 18 features (negative = the removed group helped). * = 95% paired race-bootstrap interval excludes 0. Test-season changes are in notebook §10.

  • Starting position is the backbone, but not enough on its own. Keeping only the two grid features loses 0.08–0.10 PR-AUC on validation for every model (0.05–0.08 on test), all significant. Together, the other groups add real information on top of the grid.
  • Removing one group mostly changes little, because the groups overlap (grid ↔ qualifying, standings ↔ form). The significant losses are model-specific: grid for the random forest, qualifying and standings for default gradient boosting, standings for tuned gradient boosting, context (through experience) for the logistic regression.
  • Form shows no measurable contribution as a group (its removal even raises the logistic regression by +0.015, interval −0.011 to +0.033): the standings carry the same season-long strength.
  • Single features. Removing experience alone hurts the logistic regression significantly (−0.009, interval −0.018 to −0.002); removing grid_penalty or driver_age is within noise for every model.
  • Adding back the three no-signal candidates (pit_lane_start, home_race, field_size, one at a time and all three together) never improves any model significantly; for the logistic regression every change is within ±0.001. This confirms D30.
  • No group or feature meets the removal rule in any model, so all five models keep the 18 features.
